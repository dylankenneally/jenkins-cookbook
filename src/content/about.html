Why it exists

Pipelines tend to be copied from the last project and drift from there. This cookbook is one place to copy from instead: a recipe for each of the common jobs, so you don't have to dig through the Jenkins documentation to find the pattern you need.

The recipes are meant to be copied into real pipelines, so they use placeholders instead of real values, pin their versions, and handle secrets the safe way.

What's in it

The cookbook is layered, so you can start at the level that suits you. You can also look a recipe up by tag.

How it's made

Ingredients

  • Pages written in Markdown
  • Built into a static site with Eleventy
  • Searched in the browser with Pagefind, so there is no server behind it
  • Set in IBM Plex Sans and JetBrains Mono, served from this site
  • Published on GitHub Pages

Method

  1. 01

    Edit a page. Every recipe is a Markdown file in the repository.

  2. 02

    Open a pull request. The site is built on every pull request, so a build error shows up before the change is merged.

  3. 03

    Merge to master. The change is deployed automatically.
